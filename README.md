# postulo-templates

A curated selection of document templates for Postulo: CVs, motivation letters and other
documents, in the theme format Postulo renders. Part of the postulo organisation on
source.tiagoagueda.com; contributions follow the main project's CONTRIBUTING.md.

## No version, deliberately

The plugins the project publishes carry the version of the Postulo they were released
beside; this repository carries none. A template pack is not a package: nothing installs it
from a catalogue, nothing imports it, and a template is copied into a Postulo and edited
there. What matters is which Postulo a template was written against, and that is said in
each template rather than in a number here (postulo/postulo#186).

## Translations

Nothing here is translated yet: the templates become a plugin (#1) whose words live in its
own catalogues (#7). When those exist they are a component in Weblate, at
<https://translate.tiagoagueda.com/projects/postulo/>, and that is where every translation is
made -- never in a commit, as for the rest of Postulo (postulo/postulo#706, #10).
