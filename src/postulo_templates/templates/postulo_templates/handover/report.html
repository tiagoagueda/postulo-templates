{% load i18n %} {% comment %} The job-search report made for handing to an employment service, not for keeping: the person, the office and the adviser first, then every application of the period as a table the reader can check, then a line for the date and a signature. The figures are a short list after the evidence, since an office asks for the evidence and the figures only summarise it. Not a theme over `base_report.html`, which opens with the figures: this one needs the table first, so it draws the whole page. Everything it is handed is plain values (the contract in Postulo's *Writing a plugin*), and it lays out all of it and hides nothing: choosing what a report holds belongs on the report's page. Fluid: every measure is a fraction of the page or a length that is the same on any paper, so it prints in portrait and in landscape alike, and the table's columns share the width rather than being measured against A4.
