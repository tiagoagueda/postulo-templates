{% load i18n %} {% comment %} A CV laid out as the Europass CV is (the Word template of 2013–2019): a narrow column of labels and dates, right-aligned in dark blue, and the content beside it; each section opened by its name and a thin blue rule ending in a square; Arial throughout. **A whole document rather than an extension of Postulo's `base_cv.html`.** The base sets an entry's dates beside its title, and Europass sets them in the label column, level with the title; no stylesheet can move an element into another column of the page without moving it in the markup. So this owes everything the base gives a theme, and does it the base's way: `lang` and `dir` from the document, the title and the author in the file's properties, the form of address and the pronouns each in a `` of its own, the telephone number written left to right, and only real characters between details, never CSS generated content, which is drawn and never written (postulo/postulo#235). **What it leaves out of the Word template, and why.** No Europass logo: the mark is the European Union's and is not this plugin's to print. No "© European Union" footer: it was the template's, not the person's. No five-skill language grid: Postulo keeps one level a language, and printing it in all five columns would put on somebody's CV five claims they never made; the language is printed with the level it has, and nothing where it has none. No "Job applied for" row: a CV is not written for one job here, and its headline goes under the name as the base sets it. **The icons are drawings, `aria-hidden`.** Each contact line is its value as text, so an applicant tracking system reads the value and a screen reader skips the picture. **Right to left as well.** The grid mirrors with the document's direction, so on an Arabic CV the labels are on the right and the content on the left, as Europass's own Arabic edition sets them. {% endcomment %} {{ document_title }} {% if document_author %}{% endif %} {% if document_subject %}{% endif %} {% if document_keywords %}{% endif %} {% if document_scrub %}{% endif %} /* The Word template's margins and the page number where its footer had one.
